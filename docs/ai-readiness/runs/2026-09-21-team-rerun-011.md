## P6 — Application Shell direct-element contract clarity

**Classification:** pattern contract/API clarity gap.

The runtime and TypeScript API require direct governed React elements:

- `sidebar: ReactElement<SidebarProps, typeof Sidebar>`
- `topNavbar: ReactElement<TopNavbarProps, typeof TopNavbar>`
- `pageHeading?: ReactElement<PageHeadingProps, typeof PageHeading>`

The previous machine-readable contract only encoded `{ component: "dse.sidebar" }`, which did not explicitly state that a wrapper component was invalid.

Correction:

- component-valued pattern props now support `directElement`;
- Application Shell declares `directElement: true` for Sidebar, Top Navbar, and Page Heading;
- descriptions explicitly prohibit wrappers and explain Sidebar cloning.
